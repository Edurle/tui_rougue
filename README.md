# 山海行 — 字符 Roguelike

以《山海经》异兽为对手的终端风地牢探索游戏。Python + [python-tcod](https://github.com/libtcod/python-tcod)（libtcod）渲染字符画面，**全部内容数值由 JSON 数据驱动**，为后续国风内容内核（周易占卜、天工开物合成）预留了扩展位。

**画面风格**：国潮配色（墨底/鎏金/朱砂/青瓷/紫电）× 现代等宽字体（Maple Mono NF CN）× 全套动效（光照脉动、受击闪红震屏、伤害飘字、发现提示、升级粒子、雷击特效）。

## 运行

需要 Python 3.10+：

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt pyinstaller pytest
.venv/Scripts/python main.py
```

或者直接运行打包好的单文件（无需安装 Python）：

```
dist\shanhai_rogue.exe
```

重新打包：双击 `build.bat`（或 `pyinstaller --onefile --name shanhai_rogue --add-data "assets;assets" --add-data "data;data" main.py`）。

## 玩法

**大世界 + 秘境**双层结构：开局出生在山海大陆中央的**中山经**（240×150 大世界，摄像机跟随滚动，`M` 山海图卷查看探索全图），四方环伺南/西/北/东四经，最外围是凶险的**大荒经**——契合《山海经》「大荒在四海之外」的意象。大世界有大地、森林（遮视野）、丘陵、山脉、河流（可架桥渡过）、湖泊、深渊裂谷（集中在大荒）等地形；区域之间以山脊为屏障、留山口通行，河上每隔数格有桥。

- **山川游历**：首次踏入每一经触发叙事（「南山之首曰鹊山。其阳多玉……」）；HUD 显示当前区域与最近名山（如「中山经·历儿之山」）
- **旅行**：`Shift+方向` 连续行走，撞阻/敌踪逼近/发现物品与秘境之门自动停下；任意按键打断
- **秘境**：世界各处散布 14 座秘境之门（漩涡图块 Ω），站上按 `>` 踏入——内部是经典地牢（房间+走廊，各秘境独立配色），2-5 层、越深越险，底层盘踞 BOSS（鸣蛇/九尾天狐/蛊雕王/陆吾·神陆/相柳之影/诸犊·凶王/马腹·凶灵/蠪侄/精卫/武罗/应龙/夸父/烛龙真身，均有山海经典故）。击杀 BOSS 保底掉宝、秘境永久封印。第 1 层按 `<` 回世界入口
- **难度轴**：大世界按区域递增（中山经 1 → 四经 4-10 → 大荒 16+），秘境 = 区域难度 + 层深 ×2；游荡异兽与掉落都按此投放
- **存档**：`F5` 存 / `F9` 读；进出秘境与换层自动存档；死亡即删档（roguelike 铁律）；启动可在职业选择顶部「继续游历」

### 双职业与技能

开局两段选择（主→副，共 10 职业 × 45 种组合）：属性=主职业全量 + 副职业气血/真气上限各半。每职业 8 个技能构成前置树（无等级墙，`requires` 链首即可入门），**1-8 键 = 当前职业页固定槽位**，`Tab` 切换主/副页。

- **技能点**：初始 2 点，每升一重 +1 点（14 点学不满 16 技能，取舍即构筑）；默认 1 点/链，大招 2 点
- **K 键参悟界面**：双职业分页（Tab），`✓` 已学 / `·` 可学 / `×` 前置未齐（显示缺失名），↑↓+回车学习，不消耗回合
- **真气（MP）**：按职业 8~16 起、升级 +4、抵达新山全恢复；「回气散」+8
- **目标指定**：单体技能（掌心雷、蛊毒等）进入瞄准模式——自动锁最近可见敌，`Tab` 循环、**鼠标点击**指定、回车确认、Esc 取消（不耗真气不耗回合）；位移技能（疾风步等）按方向键八向选择落点预览后回车确认；自身 AOE / 增益 / 治疗 / 召唤直接释放
- **召唤兽**（御兽师）：契约兽替你承伤与攻击，时限到化光而散

### 装备

五槽（**兵/甲/履/佩/冠**）22 件国风装备，每件 0-2 词条（雷伤+、范围+、毒伤+、疗效+、耗气-、弑回血、雷/火/毒抗、定力）。异兽死亡 22% 掉落（按层数 tier 门槛），地面罕见投放。**行囊无容量上限**（材料同类自动堆叠）。行囊分**消耗品/装备/材料三页**（`Tab` 切换，双重身份按消耗品归类），页内字母/回车使用或装备，`E` 光标操作，`1-5` 卸下对应槽位（槽位互换自动回行囊）。

### 天工开物（炼丹·炼器·炼符）

`C` 键随时打开炼制界面（不耗回合），Tab 切换三卷：

- **材料**：异兽按种类掉落（兽骨/禽羽/蛇鳞/龙鳞），BOSS 必掉**魔核**；大世界与秘境有**灵草丛/玄铁矿脉**资源点，走上去按 `G` 采集 1-2 份（出秘境时按配额复苏）；朱砂/符纸/玉屑散落地面。同类材料在行囊中**自动堆叠**
- **炼丹**（5 方）：回春丹（大治疗）/ 凝气丹（大回气）/ 解毒丹（清蛊毒）/ 蛮力丹（攻+4）/ 铁骨丹（防+4）
- **炼器**（6 方，tier 5-6 专属装备）：断水·古铗、龙鳞刀、玄铁重铠、踏云履、通灵玉佩、镇岳冠——数值高于同档掉落装备
- **炼符**（3 方）：天雷符（强雷击）/ 定身符（视野内敌全体眩晕 3 回合）/ 金刚符（防 buff）

配方与掉落映射全在 `crafting.json`（drops/nodes/recipes 三节数据驱动）。

### 抗性

异兽自带元素抗性（数据驱动，山海经考据）：**烛龙**雷/火双抗 60%（雷法/符师打不动，需换物理或毒流派）、**相柳**毒抗 60%、**毕方**火抗 60%、**九尾狐**定力 50（短眩晕直接免疫）等。元素技能伤害按抗性百分比折减（下限 1 点），蛊毒每跳同样折减，定力缩短眩晕时长——瞄准界面会显示**折算后的预计伤害与目标抗性**。部分异兽的爪击附带元素（蛊雕/相柳之毒、毕方/马腹之火、烛龙之雷火），玩家可穿**蔽火袍/雷纹冠/避毒履/清心佩**四件抗性散件应对（词条抗性上限 80%）。

## 多语言

内置 `zh_CN`（简体中文）与 `en_US`（英文）。切换方式（优先级从高到低）：

1. **开始界面 → 设置 → 语言**（`←→` 切换，即时生效并保存到 settings.json）
2. 启动参数强制：`python main.py --lang en_US`（或 `shanhai_rogue.exe --lang en_US`）
3. 未设置时自动跟随系统语言

## 开始界面与设置

启动进入开始界面：**开始新游历 / 继续游历（无存档时置灰）/ 设置 / 离开**。对局中死亡按回车也回到这里。

设置界面（开始界面 → 设置）：**语言**（中/英即时切换）、**画面大小**、**信息板宽度**——`←→` 调整即时保存，显示档位调整后自动重建窗口；`Esc` 返回。**显示设置仅可在开始界面调整**，对局中不可变更（读档/新开局按当前设置重建画面）。

- 文案：`data/content/strings/{语言}.json`，新增语言 = 加一个同结构文件
- 实体名/典故：monsters.json / items.json / player.json 中 `name`/`lore` 写成 `{"zh_CN": …, "en_US": …}`（纯字符串 = 所有语言同值；缺失语言自动回退 zh_CN）
- 语言列表在 `content_loader.py` 的 `SUPPORTED_LANGS` 登记

## 修改与扩展内容（不用改代码）

所有内容在 `data/content/`：

- **monsters.json** — 异兽定义（字符、颜色、战斗数值、AI 类型、tags、出处卷目、多语言名）
- **classes.json** — 10 职业定义（气血/攻/防/真气、双语名与简介）
- **skills.json** — 80 技能（前置树、耗气、效果参数、tags、双语名）；`tools/gen_skill_data.py` 为生成脚本
- **regions.json** — 山川游历区域表（空间 zone→经卷→难度→名山序列→首入叙事）
- **realms.json** — 8 座秘境定义（所属区域/深度/BOSS/配色主题/入口叙事）；theme.json 的 realm_themes 配各秘境配色
- **items.json** — 物品与效果（消耗品 + 五槽装备与词条）
- **spawn_tables.json** — 按难度的投放权重与数量（难度曲线：区域基础难度/秘境层深）
- **player.json** — 玩家升级加成
- **strings/** — 各语言文案模板（整体润色只动这里）
- **crafting.json** — 天工开物：材料掉落映射（drops）/资源点（nodes）/炼制配方（recipes）
- **hexagrams.json** — 周易占卜的**占位数据**（schema 已定，系统未实现）

新增一只异兽 = 在 monsters.json 加一条 + 在 spawn_tables.json 配置投放层与权重，重启即生效。新技能效果 = 在 `skills.py` 的注册表加一个类 + skills.json 引用 `effect.type`；新装备词条 = `equipment.py` 聚合逻辑 + items.json 的 `affixes` 引用；新异兽抗性/元素爪击 = monsters.json 的 `resistances`/`attack_tags` 字段。新行为/新消耗品效果才需要写代码：在 `ai.py` / `consumable.py` 的注册表加一个类，然后数据里引用类型名。

## 画面系统

- **国潮配色**：墨底 / 鎏金墙线框 / 朱砂 HUD / 青瓷地板 / 紫电雷法，全部在 `data/content/theme.json`，换肤=复制改色值
- **动效**（`effects.py`，参数在 theme 的 `effects` 节）：帧循环 60fps；光照呼吸脉动；玩家受击闪红+震屏；伤害/治疗/雷击飘字；怪物发现你的 `!` 提示；升级八向金色粒子；拾取闪光
- **邻接墙**：墙体按四邻居自动选择 ─│└┌┐┘├┤┬┴┼ 制表符，鎏金线框结构（16 种 bitmask 查表，`game_map.py`）
- **光照衰减**：视野内 3 格全亮、向外线性渐暗（`theme.json` 的 `lighting`）
- **彩色图块**：特殊实体用程序生成的图块（白色形状 + fg 调制，光照/配色自动生效）——五雷符、灵芝、尸骸、发光楼梯；JSON 加 `"art": "图块名"` 即启用，新图块在 `tileset_art.py` 注册表加生成函数
- **消息分色**：13 种语义类型（combat/heal/warn/loot/levelup…）自动着色
- **生僻字自动回退**：启动时检查内容字符的字体覆盖，缺字自动从系统字体注入（`font_fallback.py`）
- 渲染管线向量化（numpy 批量写 console.rgb）

## 字体与显示

- 主字体 **Maple Mono NF CN**（现代等宽 + Nerd 图标，OFL 授权，实测 CJK 宽高比正常）；融合像素字体保留为 `assets/font-fusion.ttf`，想换回把 `main.py` 的 FALLBACK_FONTS 顺序对调即可

- `assets/font.ttf` 为[融合像素字体](https://github.com/TakWolf/fusion-pixel-font)（12px proportional zh_hans），依 SIL Open Font License 1.1 授权，可随本程序再分发，协议全文见 `assets/font-OFL.txt`
- 显示设置两档独立（开始界面 → 设置 调整并持久化到 settings.json，对局中不可变更，默认均为**大**；统一小字多格：大=20px/64×38 格、中=16px/80×48、小=12px/106×64——信息栏内容容量随之提升，大档日志 5→15 行）：
  - **画面**（字号+格数，窗口像素基本不变）：大 32px/40×24，中 24px/53×32，小 18px/71×42（窗口 ≈1280×768）
  - **信息板**（占列数）：大 14 列 / 中 18 列 / 小 22 列，地图相应让列
- 信息板四段自适应（`settings.sidebar_layout` 行预算）：属性 → 技能页眉+8 槽 → 装备五槽 → 分隔线+日志；紧凑档（≤26 行）技能两列压缩、保日志 ≥5 行，完整档技能单列带耗气
- 布局 = 地图 + 金线分隔 + 右侧信息板；也可用 `--map`/`--sidebar` 参数指定档位启动
- 呈现时启用 `keep_aspect + integer_scaling`：窗口任意拉伸/最大化都按整数倍缩放，**不会发糊**（不足一倍的余量留黑边）

## 已知技术债

- tcod 21 对 `EventDispatch` 标记了弃用告警（建议迁移 Protocol），功能不受影响
- 行囊暂无"丢弃"操作；死亡不掉落物品
